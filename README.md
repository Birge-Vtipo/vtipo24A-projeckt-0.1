# Birge — жергілікті Next.js сайты

Next.js App Router, React, TypeScript және SQLite. Бұрынғы күлгін, ашық және алтын түсті дизайн сақталған. Сайт пен API осы компьютерде жұмыс істейді; Cloudflare немесе басқа сыртқы сервер қажет емес.

## Іске қосу

Node.js 24 қажет. CMD-де жоба папкасын ашып:

```cmd
npm.cmd ci
npm.cmd run dev
```

Келесі жолы `npm.cmd run dev` жазуға немесе VS Code-та **F5** басуға болады. Бір уақытта сервердің бір нұсқасын ғана іске қос.

Сайт: [http://127.0.0.1:3052](http://127.0.0.1:3052). Терминалда тоқтату: `Ctrl+C`, VS Code-та: `Shift+F5`. PowerShell `npm.ps1` қатесін берсе, `npm` орнына `npm.cmd` қолдан.

## Жұмыс істейтін бөлімдер

- Хабарландыру жариялау, толық қарау, өз жарияланымын өңдеу, аяқтау және жою.
- Атау/мәтін, қызмет, қала, баға, күйі, таңдаулылар және өз жарияланымдары бойынша сүзгілеу; сұрыптау.
- Адамдарды іздеу, профильдерін қарау, жазылу және жазылудан шығу.
- Жеке және топтық чат, мәтін жіберу, оқылу белгісі және хабарламалар туралы ескертулер.
- Профильдің аты, @аты, қаласы, сипаттамасы және суретін өңдеу; жарық/қараңғы тақырып.

Алғаш ашқанда тіркелусіз жергілікті қонақ профилі жасалады. Браузер cookie-файлын сақтаса, келесі ашқанда сол профильге кіреді. «Үлгі» белгісі бар адамдар — демонстрациялық деректер, олар автоматты жауап бермейді. Нақты сөйлесуді осы жергілікті серверге қосылған екі бөлек браузер профилімен тексеруге болады. Кіріс хабарламалар сайт ашық кезде бірнеше секунд сайын жаңарады; жабық браузерге push жіберілмейді.

## Деректер қайда сақталады?

`private/birge.sqlite` — жергілікті база. Жарияланымдар, профильдер, жазылулар, таңдаулылар, чаттар және хабарламалар сонда сақталады. Серверді қайта қосу базаны тазаламайды. Бұл бума Git-ке қосылмайды. Сақтық көшірме жасарда серверді тоқтатып, `private/` бумасын тұтас көшір.

Алдыңғы макетте осы браузерде сақталған профиль жаңа қонақ профиліне бір рет көшіріледі. `127.0.0.1` және `localhost` браузерде бөлек мекенжай саналады, сондықтан жоғарыдағы бір сілтемені қолдан. Cookie өшірілсе немесе басқа браузер ашылса, жаңа қонақ профилі пайда болады. Бұл нұсқада парольмен кіру және аккаунтты қалпына келтіру жоқ.

## Код құрылымы

```text
app/                   Бастапқы беттер және globals.css
app/layout.tsx         Ортақ бет және серверлік әрекеттер
components/Header.tsx  Навигация, хабарландырулар және ортақ күй
components/Board.tsx   Іздеу мен сүзгілер
components/Listings.tsx Хабарландырулар тізімі және толық көрінісі
components/Draft.tsx   Жариялау және өңдеу
components/People.tsx  Адамдарды іздеу, жазылу және аватар
components/Profile.tsx Профильді қарау және сақтау
components/Chats.tsx   Жеке және топтық чаттар
lib/types.ts           Ортақ TypeScript типтері
lib/data.ts            SQLite, деректерді тексеру және сақтау
public/                Иллюстрация
private/               Жергілікті база (Git-ке кірмейді)
.vscode/launch.json    F5 арқылы іске қосу
```

Функциялар макеттің бастапқы файлдарына енгізілген. Браузер Next.js Server Actions арқылы жергілікті серверге сұрау жібереді; базаға тек сервер қатынайды. Өзгенің хабарландыруын өзгертуге және қатысушысы емес чаттың хаттарын оқуға/жіберуге рұқсат жоқ. Хабарландырудың толық көрінісі `/board?listing=...` бетінде ашылады. `private/` ішіндегі база іске қосылғанда автоматты жасалады — ол код файлы емес.

## Тексеру және құрастыру

```cmd
npm.cmd run typecheck
npm.cmd run build
npm.cmd start
```

`build` дайын нұсқаны құрастырады; `start` оны 3052 портында іске қосады. Сайт тек `127.0.0.1` мекенжайына байланады. Интернетке жариялау немесе басқа құрылғыларға ашу бөлек баптауды қажет етеді. Бұрын сақталған `birge-next` жобасы мен ZIP архивтері өзгертілмейді.
