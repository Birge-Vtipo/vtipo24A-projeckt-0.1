# Birge

Birge — адамдарды табуға, жарияланым қосуға және жеке не топтық чатта сөйлесуге арналған сайт. Браузерді ашқан әр адамға қонақ профилі беріледі. Жергілікті нұсқада сайт, API және SQLite базасы бір компьютерде жұмыс істейді.

## Windows-та іске қосу

Node.js 24 орнатыңыз. Осы папкада CMD ашып, бірінші рет екі команданы орындаңыз:

```cmd
npm ci
START-LOCAL-WEB.cmd
```

`Ready on` шыққанда [Birge сайтын](http://127.0.0.1:8840/app/) ашыңыз. [UI/UX макеті](http://127.0.0.1:8840/#ui-ux) басты бетте орналасқан. Бірінші орнатуға интернет қажет. Кейін іске қосу үшін `START-LOCAL-WEB.cmd` жеткілікті. Интерфейс өзгерген соң серверді тоқтатып, `START-LOCAL-WEB.cmd --build` арқылы қайта қосыңыз.

## Жоба файлдары

- `app/` және `src/` — беттер мен интерфейс компоненттері (TypeScript, React Native Web, Expo).
- `cloudflare/public-page.mjs` және `cloudflare/interface-mockup.mjs` — таныстыру беті және UI/UX макеті.
- `cloudflare/` және `whatsapp-bot/src/` — API, аккаунттар, жарияланымдар мен чат логикасы.
- `scripts/local-web/` — жергілікті сервер баптаулары. Іске қосылғанда жеке кілттер мен бос база автоматты түрде жасалады. Деректер `private/local-web/state/` бумасында сақталады.
